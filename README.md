# PLP Python Week 4 Assignment

- **welcome.py**: Contains a greeting function that formats and returns a personalized welcome message for PLP students.
- **toolbox.py**: Contains utility functions for doubling numbers, checking pass/fail scores, and generating customized greetings.

The function `greet` in `toolbox.py` was slightly tricky because it required handling an optional default parameter (`greeting="Hello"`) while ensuring proper string concatenation with a comma and an exclamation mark.
